# История версий

## 1.0 — первая публичная версия

- Приём сообщений из клиентских Telegram-чатов: сторона отправителя (клиент, компания,
  система), автор-сотрудник по подписи интегратора Bitrix24 и по справочнику, ручная
  разметка «Кто это?» для спорных отправителей. Правило стороны — версия 5.
- Разметка сообщений моделью через OpenAI-совместимый API: основной профиль `gptoss-p14`
  (`openai/gpt-oss-120b`), резервный `deepseek-ds1b` (`deepseek-ai/DeepSeek-V4-Pro`),
  автоматический переход на резерв и возврат, учёт расхода и месячный потолок токенов.
- Движок обращений v4: первая реакция и ответ специалиста после передачи, окна
  «ждём клиента» и «ждём материал», отзыв просьбы, подтверждение оплаты, звонки.
  Редакция правил — `ENGINE_RULES_REVISION` в `app/services/episodes.py`.
- Сроки по рабочему календарю с праздниками и историей версий настроек.
- Алерты «Нет реакции» и «Нет ответа специалиста» с автоматическим зачёркиванием,
  сводки по алертам, вечерняя сводка, недельный и месячный отчёты.
- Отчёты: сводный, по чату, по сотруднику, «Мои показатели», «Требует внимания»,
  оперативные отчёты, автономный HTML, выгрузки XLSX и CSV, выписка переписки.
- Роли владельца, администратора и сотрудника, вход по приглашению, журнал действий,
  экран «Состояние системы».
- Эксплуатация: заслон на запись в группы, роль базы только с правами на строки,
  бэкап с шифрованием и проверкой восстановления, деплой с гейтом тестов, скрипт
  замены ключа провайдера.

Изменение поведения движка сопровождается проверкой на размеченной неделе переписки,
сменой `ENGINE_RULES_REVISION` и записью здесь.
